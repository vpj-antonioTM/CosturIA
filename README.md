# CosturIA

**Un patrón para cada tela.** Una propuesta de aplicación que combina inteligencia artificial y costura para ayudar a aprender, reparar y crear prendas.

Landing page del proyecto académico del equipo **Los tejemanejes** (Antonio Torres Martín y Sergio Sánchez Muñoz), 2º DAM, 2026.

## Publicar con GitHub Pages

1. En GitHub, abre **Settings → Pages**.
2. En **Build and deployment**, elige **Deploy from a branch**.
3. Selecciona la rama `main` y la carpeta `/ (root)`, y pulsa **Save**.
4. Cuando termine la publicación, GitHub mostrará la dirección de la página en ese mismo apartado. Para este repositorio suele ser `https://vpj-antoniotm.github.io/CosturIA/`.

La página estática utiliza HTML, CSS y JavaScript, sin proceso de compilación. El menú móvil funciona sin dependencias; las fuentes DM Sans y Manrope se cargan desde Google Fonts y usan Arial como alternativa.

> CosturIA es una idea en desarrollo presentada como proyecto académico. Las funcionalidades descritas son la propuesta del equipo, no servicios ya disponibles.
